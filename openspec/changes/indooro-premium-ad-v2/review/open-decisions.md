# Open decisions for the user

| Decision | Recommendation | Consequence if changed |
|---|---|---|
| Creative direction/duration | Approve “Der Weg wird sichtbar”, initially 32 s | A different concept requires storyboard and cue redesign |
| Film location and performer | Controlled local shoot with one actor and written releases | Without access, revise to authorized set; no production starts from unlicensed media |
| App screen truth | Use real capture if stable; otherwise approved, labeled illustrative composite | Shot 04–08 design and disclaimer placement change |
| Brand master | Approve a specific `logos/` mark or supplied vector | End card and transition glyph wait for approval |
| VO script and source | Script A, human German performer | Rhythm/word choice and licensing change with B/C or TTS |
| Distribution and aspect ratio | 16:9 web/social master first, 9:16 adaptation only if needed | Safe areas, license scope, loudness and export deliverables change |
| Spending limit | Set cap before any external purchase/service | Asset sourcing must fit cap; no purchase is authorized yet |

Only explicit user approval of production after review unlocks Phase 4 of `tasks.md`. The approval should identify any changes above; silence or a completed OpenSpec plan is not approval.
