# Open decisions before prototype acceptance and full production

| Decision | Recommendation | Why it matters |
|---|---|---|
| Prototype acceptance | Review the four rendered drafts at normal speed and explicitly accept or request changes | The user's prototype authorization has been exercised; full-film production has a separate gate |
| Brand master | Select approved Indooro mark from `logos/` or supply vector | Route can create or frame the mark without inventing/distorting identity |
| Illustrative UI truth | Approve `Milch` search/result/map copy and appropriate concept disclosure | Prevent a generated screen or spatial route from implying unsupported shipping behavior |
| Voice | Prefer minimal Script A and an authorized German synthetic voice; B/C or authorized human read remain options | Scratch VO timing and rights depend on selection |
| Distribution | Confirm 16:9 web/social first and any 9:16 need | Safe areas, final audio target and rights scope depend on channel |
| Optional spend | Set a cap for voice/music/sample services if used | Visuals need no stock footage budget |

Blender CLI was preflighted and used in P1/P3/P4. Remotion 2.5D remains the P3 fallback if the composited camera handoff is impractical at final quality. Actor, filming location and live footage are not dependencies. The four prototypes must be reviewed and explicitly accepted before navigation shots or the full 26-second film begin. Silence is not approval.
