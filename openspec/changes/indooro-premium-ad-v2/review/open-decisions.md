| Optional spend | Set a cap for voice/music/sample services if needed | Code-generated visuals need no stock-footage budget |

Blender availability is a **future technical preflight**, not a user choice or hard dependency; Remotion-only fallback covers the full approved story. Actor, film location and live footage are not requested. Silence or a complete OpenSpec plan is not production approval.
