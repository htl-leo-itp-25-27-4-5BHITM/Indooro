# Preview-first render strategy — future work only

No V2 scene, Blender project, preview or soundtrack is created during concept revision. After approval, use 30 fps and an initial 840-frame timeline. Render brief 1280×720 H.264/yuv420p ranges for the figure, hero phone, route handoff and end card. For 3D, start with one still and a 1–2 s draft pass before any full shot; retain a frame-numbered source sequence and hash manifest. Use Remotion SVG/2.5D fallback immediately if a 3D pass looks toy-like, exceeds practical render time or cannot be scripted reproducibly. Higher-resolution stills verify UI type and the route's depth/occlusion.

Then export a complete 720p rough cut with labeled temporary VO/music, review muted and with sound, revise, approve picture and final mix, and only after explicit final-render approval export 1920×1080 H.264/AAC. Verify 840 frames if 28 s remains final, 30 fps, correct codec/pixel format, readable phone/result/end card, route on walkable geometry, figure continuity, no blank boundary, true peak/loudness and human listening. An adjusted 25–30 s cut must update storyboard, cue sheet and frame count together. Generated passes and master files can remain outside Git if their scripts, provenance, hashes and delivery location are recorded.
