# Preview-first render strategy

Do not render any V2 content during this planning assignment. After approval, use 30 fps source and a **1280×720 H.264/yuv420p** draft preset with AAC from separate temporary stems. Generate short frame ranges for hook, human/phone, route transition and final card, then a complete low-resolution rough cut. Use reduced bitrate for timing reviews; render high-resolution stills where UI typography, tracking/occlusion, reflections or logo edges need inspection. A draft label should identify temporary VO/music.

Review sequence: prototype approval → complete rough cut watched muted and with sound → pacing/VO revision → refined cut and rights review → final mix listening → explicit final quality render approval → 1920×1080 H.264/AAC export. At each stage record time-coded feedback and changed frame ranges. Final checks: 960 frames if duration remains 32 s (or updated exact contract), 30 fps, no blank cut frames, appropriate codec/pixel format, audio tail and true peak, route legibility at 720p, approved branding and no unsupported product claim. Preserve source project and a hash manifest; large generated media can remain outside Git if delivery storage is explicit.
