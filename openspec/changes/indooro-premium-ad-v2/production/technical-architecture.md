# Proposed technical architecture — planning only

**Chosen pipeline:** Remotion + short, scripted Blender passes. Remotion owns the 28-second/840-frame master composition, UI, SVG route, 2.5D fallback, type, transitions, VO/music/SFX and final export. Blender Python may generate a modular store, primitive faceless shopper, phone body and selected spatial camera shots. Only a few seconds of 3D need rendering. No live-action or generated video-service footage is needed. Cinema 4D adds no necessary capability and is excluded from the core pipeline.

After approval, create isolated `indooro-ad-v2/`: `src/timeline/`, `src/shots/`, `src/ui/`, `src/map/`, `src/graphics/`, `src/audio/`, `blender/scripts/`, `blender/scenes/`, `public/3d-passes/`, `public/audio/{voice,music,sfx}/`, `public/brand/`, `previews/`, `exports/`, and an asset manifest. This structure is a proposal, not a directory to initialize now. Copy selected V1 helpers into V2 with provenance rather than importing V1 production paths at runtime.

One illustrative `store-layout.json` is the geometry contract: shelf blocks, walkable cells, entrance, milk access node, route points, palette and coordinate units. TypeScript calculates/checks the walkable route; a Blender Python builder uses the same source to place shelves, target, figure and camera presets. The 2D phone path reaches a chosen frame edge/tangent; a generated store path begins at the matched point. This makes the handoff deterministic without camera tracking. In Blender shots, depth/occlusion are baked into short opaque image sequences; selected transparent object passes may be RGBA PNGs. Remotion combines the frames at fixed indices with crisp UI text and sound. Render only after approval. [Blender's command-line manual](https://docs.blender.org/manual/en/5.1/advanced/command_line/render.html) confirms background rendering; [its license page](https://www.blender.org/about/license/) describes use of Blender and ownership of created artwork.

**Fallback contract:** If Blender is unavailable or a 3D pass fails the premium quality review, Remotion recreates the same framing with layered SVG shelf planes, a multi-pose adult silhouette, gradients, masks, parallax and frame-based transforms. The story, product, route geometry and sound cues stay unchanged. Blender is not presently in this host's `PATH`; installation and a still/short-pass preflight are future approved work. The visible Cinema 4D installation is not assumed to be automatable or licensed for this job.

Pin compatible Remotion/React/TypeScript dependencies. Fix all timing in one 30 fps shot/cue module. Use deterministic seeds, local assets, no network fetch during render and hash generated passes. Asset manifest fields: id, source script or license, version, owner, checksum, frame count, dimensions, alpha/color treatment and approval state. QA covers route geometry, preview readability, repeated-frame hashes, shot boundaries, audio loudness/peak and actual human watch/listen reviews. The V1 project remains independently renderable.
