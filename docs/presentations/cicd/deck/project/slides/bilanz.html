Bilanz

Was gut läuft, was fehlt

Gut

  • Jeder PR: Vertrag, Backend mit echtem OpenSearch, zwei Browser-Suiten, iOS
  • Breaking Changes an der API werden automatisch erkannt
  • Fester SHA-Tag, Rollback und Backup dokumentiert
  • Claude-PRs durchlaufen dieselben Checks

Fehlt

  • Kein Continuous Deployment, Rollout nur mit Eriks Zugang
  • main ohne Branch-Schutz, keine GitHub-Reviews
  • Browsertests blockieren den Image-Build nicht
  • iOS nur Tests, kein TestFlight; Android ohne Pipeline
Ehrlich bleiben. Fakten aus GitHub: main hat keinen Branch-Schutz und keine Rulesets, grüne Checks sind also eine Teamregel, nicht erzwungen. Keiner der letzten 133 gemergten PRs hat ein formales GitHub-Review. build-and-push wartet nur auf contract und backend-test. Nächste Schritte wären Branch-Schutz mit Pflicht-Checks und ein Deploy-Workflow mit manueller Freigabe, falls die LeoCloud einen Zugang für CI erlaubt.
