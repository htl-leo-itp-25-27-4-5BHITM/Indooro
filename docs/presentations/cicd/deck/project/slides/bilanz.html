Bilanz

Was gut läuft, was fehlt

Gut

  • Über 3.200 automatische Tests, bei jedem PR mindestens 1.780
  • Echter Browser und echte Datenbank in den Tests
  • Jede Version eindeutig benannt, Rückweg dokumentiert
  • Code von Claude geht durch dieselben Tests

Fehlt

  • Live gehen nur von Hand, nur mit Eriks Zugang
  • main ist nicht gesperrt: Mergen ginge auch bei roten Tests
  • Kein zweiter Mensch prüft den Pull Request auf GitHub
  • iOS wird nur getestet, nicht verteilt; Android hat noch keinen Code
Ehrlich bleiben. Fakten aus GitHub: main hat keinen Branch-Schutz. Dass wir nur mit grünen Tests mergen, ist eine Teamregel, technisch erzwungen ist es nicht. Keiner der 133 gemergten Pull Requests hat ein formales Review auf GitHub, geprüft wird in der Claude-Session und vom Menschen, der mergt. Nächste Schritte wären: main sperren, sodass rote Tests den Merge blockieren, und ein Deploy-Knopf in GitHub mit Freigabe, falls die LeoCloud das erlaubt.
