Geht etwas schief: alte Version wieder einspielen (Rollback). Anleitung: docs/pilot-readiness/operations/RELEASE_RUNBOOK.md

Das ist der Teil, den wir bewusst von Hand machen. Erik macht das mit seinem LeoCloud-Zugang, manchmal lässt er Claude Code die Befehle ausführen, aber nur auf ausdrückliche Anweisung. Der wichtigste Befehl ist kubectl set image: Er sagt Kubernetes, welche Version laufen soll, und Kubernetes holt sie selbst aus dem Lager. Smoke-Check heißt: ein kurzer Test, ob die wichtigsten Seiten antworten, wie Rauch, der zeigt, ob etwas brennt. Jedes Release ist in docs/pilot-readiness/releases protokolliert.
