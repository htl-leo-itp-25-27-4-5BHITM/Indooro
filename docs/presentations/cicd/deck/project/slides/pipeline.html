Branch

Pull Request

gegen main, startet die Checks

GitHub Actions

Vertrag, Tests, Browser, Build

GHCR

nach Merge: Image mit Tag = Commit-SHA

LeoCloud

kubectl set image, von Hand

Continuous Integration

Continuous Delivery

Manuell

Die LeoCloud zieht das Image aus GHCR. Kein Workflow hat Zugang zum Cluster.

Das ist das wichtigste Bild. Links bis GitHub Actions ist CI. Das fertige Image in der GitHub Container Registry ist Continuous Delivery. Der letzte Pfeil ist gestrichelt, weil er manuell ist. Wichtig: GitHub schiebt nichts in die LeoCloud. Kubernetes zieht das Image, sobald jemand mit kubectl den neuen Tag setzt.
