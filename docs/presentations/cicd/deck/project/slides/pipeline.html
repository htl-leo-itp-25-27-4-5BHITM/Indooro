Continuous Integration

Continuous Delivery

Von Hand

Schritt 1 bis 4 laufen von selbst. Nur der gestrichelte Pfeil braucht einen Menschen.

Das ist das wichtigste Bild, am besten von links nach rechts durchgehen. Eins: Jemand schreibt Code auf einem eigenen Branch, entweder wir oder Claude Code. Zwei: Ein Pull Request auf GitHub. Drei: GitHub Actions startet automatisch alle Tests. Vier: Wenn alles grün ist und gemergt wurde, baut GitHub ein Docker-Image und legt es in GHCR ab. Fünf: Erik holt dieses Image mit einem Befehl in die LeoCloud. Dieser letzte Pfeil ist gestrichelt, weil er von Hand passiert.
