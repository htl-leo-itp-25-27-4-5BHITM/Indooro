Begriffe

Drei Stufen, eine Frage: Wie weit läuft es automatisch?

Continuous Integration

Jede Änderung wird früh in den Hauptzweig integriert. Ein Server baut und testet sie automatisch.

Continuous Delivery

Nach grüner CI entsteht automatisch ein auslieferbares Paket. Ein Mensch entscheidet, wann es live geht.

Continuous Deployment

Jede grüne Änderung geht ohne menschlichen Schritt automatisch in Produktion.

CI = bauen + testen · Delivery = Paket liegt bereit · Deployment = Paket geht automatisch live

Der Unterschied liegt nur im letzten Schritt. Bei Continuous Delivery liegt das fertige Paket bereit und ein Mensch drückt auf den Knopf. Bei Continuous Deployment gibt es diesen Knopf nicht mehr. Bild: Paket gepackt und abholbereit gegen Paket wird automatisch zugestellt.
