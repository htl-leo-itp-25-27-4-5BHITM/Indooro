# Working conventions

1. Preserve the 1,950-frame / 30 fps timing contract.
2. Render from Remotion source; avoid wall-clock CSS animation and unseeded randomness.
3. Use the illustrative store graph for all map scenes; route lines must follow walkable cells.
4. Keep text short and readable at half-resolution preview.
5. All audio is original synthesis or documented authorized material.
6. Run typecheck and route tests before exports; inspect actual stills and media metadata.
7. Keep `../openspec/changes/indooro-motion-graphics-film/tasks.md` truthful.
