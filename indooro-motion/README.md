# Indooro motion graphics film

An editable 65-second, German-language Remotion product film. The mobile and admin interfaces are illustrative concepts based on the current Indooro repository. It uses no SPAR branding or measured performance claims.

## Setup

Requires Node 20+ and npm. From this directory:

```bash
npm ci
npm run audio
npm run typecheck
npm run routes:test
npm run dev
```

Remotion Studio shows `IndooroFilm`, eight standalone scene compositions, and `IndooroPoster`.

## Render

```bash
npm run render:preview
npm run render:final
npm run render:poster
```

Outputs appear in `exports/`. The main composition is 1920×1080, 30 fps, 1950 frames. Preview uses half-size output. Rendering uses Remotion's FFmpeg-based pipeline. The soundtrack is generated by `scripts/generate-audio.mjs` from oscillators and procedural noise, with no third-party samples. The score is a local WAV asset; its source recipe is included.

Planning, storyboard, asset inventory, and verification requirements are in `../openspec/changes/indooro-motion-graphics-film/`. No Indooro app/backend process is required.
